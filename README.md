### $ whoami

I'm a DevOps engineer focused on infrastructure as code, Kubernetes and CI/CD automation.
I don't ship features — I ship the platforms that features run on: self-managed clusters
provisioned from bare VMs, hardened against security benchmarks, and wired into reproducible
pipelines. When the terminal needs a break, I maintain small tooling for the
niri Wayland compositor.

     ▸ Base — Italy · remote-friendly
     ▸ Focus — Kubernetes · IaC · CI/CD · Linux
     ▸ Now exploring — GitOps (ArgoCD) · Prometheus & OpenTelemetry · Go for ops tooling
     ▸ Ask me about — cluster provisioning · pipeline design · dotfiles
